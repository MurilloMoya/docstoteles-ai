## Options [​](https://ohmyposh.dev/docs/segments/web/http\#options "Direct link to Options")

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `url` | `string` | \`\` | The HTTP URL you want to call, supports [templates](https://ohmyposh.dev/docs/configuration/templates) |
| `method` | `string` | `GET` | The HTTP method to use, `GET` or `POST` |
| `http_timeout` | `int` | `10000` | The timeout in milliseconds for the HTTP request |
