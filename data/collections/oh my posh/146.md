## What [​](https://ohmyposh.dev/docs/segments/system/winget\#what "Direct link to What")

Displays the number of available [WinGet](https://learn.microsoft.com/windows/package-manager/winget/) package updates. This segment only appears when there are updates available.

info

This segment is only available on Windows.

### Properties [​](https://ohmyposh.dev/docs/segments/system/winget\#properties "Direct link to Properties")

| Name | Type | Description |
| --- | --- | --- |
| `.UpdateCount` | `int` | the number of packages with available updates |
| `.Updates` | `[]WinGetPackage` | array of packages with available updates |

### WinGetPackage [​](https://ohmyposh.dev/docs/segments/system/winget\#wingetpackage "Direct link to WinGetPackage")

| Name | Type | Description |
| --- | --- | --- |
| `.Name` | `string` | the package name |
| `.ID` | `string` | the package ID |
| `.Current` | `string` | the currently installed version |
| `.Available` | `string` | the available version for update |
