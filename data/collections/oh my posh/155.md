## What [​](https://ohmyposh.dev/docs/segments/cli/zvm\#what "Direct link to What")

Display the active Zig version reported by [ZVM](https://github.com/tristanisham/zvm) (Zig Version Manager).

The segment is only enabled when the `zvm` command is available and a version is currently in use.

## Options [​](https://ohmyposh.dev/docs/segments/cli/zvm\#options "Direct link to Options")

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `zigicon` | `string` | `ZVM` | the icon to display before the version |

## Template ( [info](https://ohmyposh.dev/docs/configuration/templates)) [​](https://ohmyposh.dev/docs/segments/cli/zvm\#template-info "Direct link to template-info")

### Properties [​](https://ohmyposh.dev/docs/segments/cli/zvm\#properties "Direct link to Properties")

| Name | Type | Description |
| --- | --- | --- |
| `.Version` | `string` | the active Zig version used by `zvm` |
| `.ZigIcon` | `string` | the configured `zigicon` |
