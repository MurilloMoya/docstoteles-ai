## What [​](https://ohmyposh.dev/docs/segments/web/todoist\#what "Direct link to What")

Displays your daily tasks from [Todoist](https://www.todoist.com/).

caution

The segment needs an [API Key](https://www.todoist.com/help/articles/find-your-api-token-Jpzx9IIlB) from your Todoist profile for this to work.

## Options [​](https://ohmyposh.dev/docs/segments/web/todoist\#options "Direct link to Options")

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `api_key` | `string` | `.` | Your API Key from [Todoist](https://www.todoist.com/) |
| `http_timeout` | `int` | `20` | The time ( _in milliseconds_, `ms`) it takes to consider an http request as **timed-out**. If no segment is shown, try increasing this timeout. |
